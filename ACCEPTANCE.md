# Результат локальной проверки

Проверено 15 ноября 2026 года. Python 3.14, Django 5.2.19, SQLite, Windows. 28 автоматических тестов Django прошли; `check`, `check --deploy` с production-настройками и `makemigrations --check --dry-run` выполнены без замечаний.

| Сценарий ТЗ | Проверка |
| --- | --- |
| К1: гость и начальное наполнение | Проверены 3 эпохи, 9 тем, 36 карточек, приглашение войти перед тестом |
| К2: совместные фильтры и поиск | Поиск по кириллице без учёта регистра, эпоха и тип, пустая выдача |
| К3: регистрация и повторный вход | Регистрация, хеширование пароля, сохранение отметки после выхода |
| К4: отметки чтения | Повторный POST без дублей, снятие отметки, изменение процента |
| К5: минивикторина | 0/5 баллов и разбор после завершения |
| К6: итоговый тест | Результат 3/5, 60%, 30 баллов, разбор пяти вопросов |
| К7: лучший результат | Три попытки 20, 40, 30; вклад 40 |
| К8: повторная отправка | Результат не меняется, ответы не дублируются |
| К9: подмена ID | Чужая попытка возвращает 404, чужой вариант отвергается, частичного сохранения нет |
| К10: черновики и скрытые родители | Прямые ссылки на эпоху, тему, карточку, тест и незавершённую попытку недоступны |
| К11: публикация | Модель блокирует неполный тест/тему, валидный тест публикуется; действие админки показывает ошибки валидации |
| К12: максимум | Дважды пройдены все тесты без ошибок; счёт 195, 24 отдельные попытки |
| К13: интерфейс | Chromium: 36 проверок раскладки на 360/768/1440 px; клавиатурная ссылка к содержимому, раскрытие карточки, меню |
| К14: установка и seed | На новой локальной базе применены миграции и seed; повторный seed сохраняет количество данных и результаты |

Браузером также проверены вход ученика и администратора, сохранение/снятие отметки, завершение теста и показ разбора. Изображения на проверенных страницах загружаются. Ошибок JavaScript нет. Скриншоты и машиночитаемый отчёт — в локальной папке `test-results/` (исключена из Git).

Ограничения проверки: Docker/PostgreSQL и внешний HTTPS-сервер в этой среде не запускались. Реальная конкурентная отправка под PostgreSQL, Firefox и Safari остаются проверками развёрнутой версии. В коде завершение попытки использует транзакцию и блокировку строки PostgreSQL; SQLite-тест проверяет последовательную повторную отправку. Проект запущен локально, не опубликован на внешнем домене. Инструкция развёртывания и восстановления приведена в README.
